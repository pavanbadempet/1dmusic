> Minimalist Android Material Design music player application featuring local audio playback, dynamic queueing, and lightweight resource utilization.

---

## 🎵 Features
- **Material Design UI**: Clean, responsive audio playback interface adhering to Android Material guidelines.
- **Local Library Playback**: Efficiently indexes audio files from local device storage without heavy background indexing.
- **Dynamic Queue Management**: Seamless playlist ordering, shuffle, repeat, and persistent playback state.
- **Lightweight Footprint**: Optimized resource management for battery and memory efficiency.

## 🛠️ Tech Stack & Architecture
- **Language**: Java / Kotlin
- **Architecture**: Android MVP with Service-based background media playback
- **Build System**: Gradle / Android Build Tools

## 🚀 Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/pavanbadempet/1dmusic.git
   ```
2. Open the project in **Android Studio**.
3. Sync Gradle dependencies and build the debug APK:
   ```bash
   ./gradlew assembleDebug
   ```
